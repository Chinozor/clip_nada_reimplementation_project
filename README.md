# CLIP + NADA Reimplementation Project

Адаптация **StyleGAN2 (FFHQ лица)** под новые домены с помощью **CLIP** (Directional loss) + выбор обучаемых слоёв через **Global Loss**.

Проект содержит код для обучения, конфигурации экспериментов и ноутбуки с запуском и визуализацией результатов. Цель — перенести распределение генерируемых лиц в целевой домен, сохранив идентичность и качество.

## Что мы сделали и как это работает
Мы переиспользуем **StyleGAN2 (FFHQ лица)** и адаптируем генератор под новый домен с помощью **CLIP-направленных лоссов** (Directional loss), не переобучая сеть с нуля. Ниже — кратко о ключевых шагах:

1. **Направление в пространстве CLIP.** Берём текстовое описание исходного домена (например, «photo») и целевого домена (например, «sketch»). CLIP позволяет получить вектор направления между этими описаниями. При обучении сравниваем, насколько сгенерированное изображение «двигается» в этом направлении относительно базового генератора.
2. **Directional loss.** Лосс поощряет, чтобы изменение в изображении от базовой модели к адаптированной совпадало с текстовым направлением. Это позволяет изменять стиль/домен, сохраняя идентичность и структуру лица.
3. **Global Loss и выбор слоёв.** Оцениваем вклад слоёв в глобальную трансформацию и обучаем только те части генератора, которые сильнее всего отвечают за перенос домена. Это снижает риск деградации качества и предотвращает «ломку» геометрии.
4. **Разморозка слоёв (freezing).** Слои подбираются и постепенно размораживаются, чтобы обеспечить стабильную адаптацию и избежать резких скачков в качестве.

Итог: получаем перенос домена (style transfer на уровне генератора) без полного переобучения — качество лица сохраняется, а визуальные характеристики соответствуют целевому домену.
